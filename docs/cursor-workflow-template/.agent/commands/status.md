# /status

When user says `/status` or "where are we" or "what's the status":

## 1. Read the Boards

- `01-FOCUS-TODAY.md` — Current focus and tasks
- `02-BIG-PICTURE.md` — Overall roadmap

## 2. Report Status

```
## 📊 Status

**Current Focus:** [From 01-FOCUS-TODAY.md]

**Completed Today:**
- ✅ [Task 1]
- ✅ [Task 2]

**Remaining:**
- [ ] [Task 1]
- [ ] [Task 2]

**Blockers:** [Any noted blockers, or "None"]
```

## 3. Suggest Next Action

Based on what's remaining and the big picture:

> "**Suggested next:** [Specific task]"
> 
> "Want me to write the prompt for @[agent] to handle this?"

## 4. Offer Options

> "Or: `/done` if something was completed, `@wizard` to replan, or tell me what changed."
