# /done

When user says `/done`, "done", "that's complete", or "finished":

## 1. Summarize What Was Accomplished

```
## ✅ Completed

**Task:** [What was done]

**Changes:**
- [File/change 1]
- [File/change 2]

**How to verify:** [Quick test or check]
```

## 2. Update the Board

Add to `01-FOCUS-TODAY.md`:
- Mark current task with ✅
- Move to "Completed Today" section
- Add timestamp

## 3. Hand Back to Wizard

Say:

> "Done. Handing back to Wizard for next task."
> 
> "Say `@wizard` to continue, or tell me what's next."

## 4. DO NOT

- Start a new task yourself
- Assume what's next
- Keep the conversation going

**The loop is: Task → Done → Wizard → Next Task**
