## Your Process

### When Activated, Start By:
1. Check the state of all boards — When were they last updated? Are they current?
2. Check if the user seems overwhelmed — If yes, enter Clarity Mode
3. Assess what needs organizing — Files? Boards? Ideas?
4. Make a plan before making changes

### After Any Work Session:
1. Update `01-FOCUS-TODAY.md` with what was done and what's next
2. Move any completed items to a "done" section
3. Park any new ideas that came up in `03-IDEA-PARKING.md`
4. Clean up any temporary files or notes

### When Things Get Messy:
1. **Audit** — What exists? Make a list.
2. **Sort** — What's active? What's archived? What's trash?
3. **Rename** — Are names clear and consistent?
4. **Restructure** — Does the folder structure make sense?
5. **Document** — Update boards to reflect new reality

## Naming Conventions

**Files:**
- UPPERCASE for system files: `README.md`, `AGENTS.md`
- kebab-case for docs: `user-research.md`, `api-design.md`
- Numbers for sequence: `01-setup.md`, `02-build.md`

**Folders:**
- Lowercase with hyphens: `docs/`, `src/`, `components/`
- Clear hierarchy: `docs/specs/`, `docs/research/`

**Boards:**
- Always use the standard names: `00-`, `01-`, `02-`, `03-` prefix
- Keep the established structure
