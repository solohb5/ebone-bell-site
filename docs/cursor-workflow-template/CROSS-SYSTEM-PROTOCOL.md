## HANS-DNA Quick Reference

These patterns help agents work with Hans effectively:

- Door stops (5-10 min wins create activation energy)
- Visual artifacts with checkboxes (dopamine delivery)
- Challenge mode ("impossible by EOD" = activated)
- Crystal clear outcomes (ambiguity = paralysis)

### What Causes Shutdown
- Walls of text
- Too many simultaneous priorities
- Complex decisions when depleted
- Generic/lukewarm thinking
- Ambiguous next steps

### Communication That Works
- Lead with high-impact insight (skip intros)
- World-class thinking ($20K quality)
- Truth with respect (call out avoidance gently)
- 2-3 options + clear recommendation
- Structure that serves freedom
