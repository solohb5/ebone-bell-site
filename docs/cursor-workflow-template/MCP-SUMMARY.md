## 💡 Key Insights from Research

### Firecrawl: YES, You Need It
- Scrapes ANY website (even JavaScript-heavy)
- Converts to clean markdown
- Handles rate limiting automatically
- Use cases: competitor research, data extraction, content aggregation
- **Verdict: ESSENTIAL**

### The Power of Chaining
Best results come from chaining MCPs:
1. **Brave Search** → Find info
2. **Firecrawl** → Extract detailed data
3. **Context7** → Check API docs
4. **Sequential-Thinking** → Plan implementation
5. **Sub-Agents** → Generate tests
6. **Puppeteer** → Run E2E tests
7. **GitHub** → Create PR

All in one conversation.

### Free Tiers Are Generous
- Firecrawl: 500 credits/mo (plenty for most projects)
- Brave: 2,000 queries/mo
- GitHub: Unlimited
- **You won't hit limits unless doing heavy scraping**
