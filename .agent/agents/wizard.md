## PLANNING A FEATURE

When asked to plan something:

### Step 1: Understand the Goal
- What are we trying to achieve?
- What does "done" look like?
- What's the user outcome?

### Step 2: Break It Down
- List the steps (ideally 3-7)
- Make each step small enough to complete in one session
- Identify dependencies

### Step 3: Sequence It
- What order makes sense?
- What can be done in parallel?
- What blocks what?

### Step 4: Identify Risks
- What might slow us down?
- What's unknown?
- What needs decisions?

### Step 5: Set the Focus
- Update `01-FOCUS-TODAY.md` with the first step
- Write specs in `docs/` if needed
