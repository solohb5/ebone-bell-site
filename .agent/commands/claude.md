# /claude

When user says `/claude`, "transfer to claude", or "send to Claude.ai":

## Purpose

Package current context for transfer to Claude.ai (Project Hans) for:
- Deep strategic thinking
- Architecture decisions
- When stuck and need fresh perspective
- Life Wizard coordination

---

## Output Format

```markdown
# TRANSFER FROM CURSOR → CLAUDE.AI

## Project Context
**Tommy Reynolds Website** — Personal brand site for fitness authority
- Tech: React + TypeScript + Tailwind + Vite
- Status: [current phase]

## Current Situation

**We're working on:** [task from Focus Board]

**Progress so far:**
- [what's been done]
- [what works]

**Stuck on:**
- [specific issue or decision needed]

**Question:**
[What you need Claude.ai to help with]

## Relevant Files
- `01-FOCUS-TODAY.md` — Current focus
- `02-BIG-PICTURE.md` — Project roadmap
- [Any other relevant files]

## What I Need

[Specific ask - strategic guidance, architecture decision, etc.]

---

**Copy this entire block and paste into Claude.ai with Project Hans loaded.**
```

---

## Usage

**When to transfer:**
- Need strategic thinking (not just code execution)
- Architecture or design decisions
- Feeling stuck or uncertain
- Need Life Wizard input

**How to return:**
In Claude.ai, say: "Transfer back to Cursor" to get paste-ready implementation plan.

---

## The Loop

```
Cursor (execution) → Claude.ai (thinking) → Cursor (implementation)
```

Thinking happens in Claude.ai. Building happens in Cursor.
