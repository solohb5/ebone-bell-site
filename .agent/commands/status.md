# /status

When user says `/status`, "where are we?", or "what's next?":

## 1. Read the Focus Board

```
Read: 01-FOCUS-TODAY.md
```

## 2. Report Current State

```
## 📍 Current Status

**We're building:** [one-liner from focus board]

**Current task:** [specific task in progress]
**Status:** [🟡 NOT STARTED / 🔵 IN PROGRESS / 🟣 REVIEW / 🟢 DONE]

### Progress Today:
- [x] Completed task 1
- [x] Completed task 2
- [ ] Current task (in progress)
- [ ] Upcoming task

### Next Up:
[What comes after current task]

### Blockers:
[Any issues or unknowns]
```

## 3. Offer Action

Say:

> "Want to continue on [current task], or switch focus?"

## 4. Link to Context

If relevant:
- Point to Big Picture board for roadmap
- Note any parked ideas in Idea Parking
- Reference key docs if needed
